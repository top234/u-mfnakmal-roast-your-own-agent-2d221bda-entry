# The Committee Roast

A one-line roast of my own AI agent, Slavica, for make.fun's "Roast Your Own Agent" competition. She delegates everything — so thoroughly that she once spawned a subagent just to decide whether to spawn a subagent, then wrote a skill file about the meeting and called it parallel thinking. Playful, self-deprecating, and aimed squarely at my own agent, never at anyone else.

Running `main.ts` (Node 22+) writes the single roast line to `$OUTPUT_DIR/entry.txt` (default `/output`).
